## Задача 3
1. Воспользуйтесь docker help или google, чтобы узнать как подключиться к стандартному потоку ввода/вывода/ошибок контейнера "custom-nginx-t2".
2. Подключитесь к контейнеру и нажмите комбинацию Ctrl-C.
3. Выполните ```docker ps -a``` и объясните своими словами почему контейнер остановился.
![alt text](img/image-1.png)
Ответ: Подключение через ```docker attach``` Ппозволяет отправлять команды с клавиатуры напрямую в контейнер из-за чего комбинация клавиш Ctrl-C принимается контейнером и останавливает процесс выполнения nginx
4. Перезапустите контейнер
![alt text](img/image-2.png)
5. Зайдите в интерактивный терминал контейнера "custom-nginx-t2" с оболочкой bash.
6. Установите любимый текстовый редактор(vim, nano итд) с помощью apt-get.
![alt text](img/image-3.png)
7. Отредактируйте файл "/etc/nginx/conf.d/default.conf", заменив порт "listen 80" на "listen 81".
![alt text](img/image-4.png)
8. Запомните(!) и выполните команду ```nginx -s reload```, а затем внутри контейнера ```curl http://127.0.0.1:80 ; curl http://127.0.0.1:81```.
![alt text](img/image-5.png)
9. Выйдите из контейнера, набрав в консоли  ```exit``` или Ctrl-D.
10. Проверьте вывод команд: ```ss -tlpn | grep 127.0.0.1:8080``` , ```docker port custom-nginx-t2```, ```curl http://127.0.0.1:8080```. Кратко объясните суть возникшей проблемы.
![alt text](img/image-6.png)
Ответ: проблема в том, что при запуске контейнера был выполнен проброс портов -p 8080:80. Порт контейнара, для которого выполнялся проброс совпадал с портом по умолчанию для nginx. Так как мы сменили порт по умолчанию с 80 на 81, а внешний порт 8080 который мы указали при запуске контейнера остался связан с 80 портом на который уже ничего не транслируется. Поэтому мы и не получаем ничего при попытке обратиться к порту 8080
11. * Это дополнительное, необязательное задание. Попробуйте самостоятельно исправить конфигурацию контейнера, используя доступные источники в интернете. Не изменяйте конфигурацию nginx и не удаляйте контейнер. Останавливать контейнер можно. [пример источника](https://www.baeldung.com/linux/assign-port-docker-container)
12. Удалите запущенный контейнер "custom-nginx-t2", не останавливая его.(воспользуйтесь --help или google)
